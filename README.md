# h「ito」ri

意思疎通カードゲーム「ito」を1人で遊べるWebアプリケーション。

## 技術スタック

| カテゴリ | 技術 |
|---|---|
| フロントエンド | React (TypeScript) / Vite |
| バックエンド | Go / Echo |
| 認証 | Supabase Auth |
| DB | Supabase (PostgreSQL) |
| コンテナ | Docker |
| CI/CD | GitHub Actions |
| ドメイン・DNS | Cloudflare |
| CDN・フロント配信 | CloudFront + S3 |
| APIサーバー | ECS Fargate + ECR |
| ロードバランサー | ALB |
| ネットワーク | VPC（パブリックサブネットのみ） |
| SSL証明書 | ACM |
| IaC | Terraform |
