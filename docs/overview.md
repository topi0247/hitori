# アプリ概要

- **アプリ名：** h「ito」ri（読み：ひとり）
- **コンセプト：** ひとりでできるito
- **概要：** 意思疎通カードゲーム「ito」を1人で遊べるWebアプリケーション

## フェーズ

### MVP第1弾
- トップ画面
- 登録・ログイン
- ゲーム画面（1画面・ステップ形式）
  - 枚数指定（4〜10枚）
  - 自分の言葉設定
  - 並び替え（ドラッグ＆ドロップ、スマホ対応）
  - 結果
  - 自分の言葉確定
- アカウント設定画面
  - ユーザー名変更
  - 退会（退会してもカードは削除しない）
- マッチポイント機能（裏でロジックのみ・表示なし）

### MVP第2弾
- マッチポイント表示
- 再プレイによるカード編集機能
- マイページ（投稿したカード一覧）

### 最終リリース
- お題投稿機能
- 難易度拡張（MVP様子見で検討）
- マッチポイントユーザー投票（MVP様子見で検討）
- マイページにお題一覧

### 実装しない
- カード・お題の削除（開発者モデレーションのみ）

### いつかやりたい
- 言葉確定時のAI不適切判定
- 禁止お題・禁止言葉設定
